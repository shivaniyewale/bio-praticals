import pandas as pd

from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# Read Dataset
data = pd.read_csv("genomic_data.csv")

print("Genomic Dataset\n")
print(data)

# Features
X = data[["GeneFeature1", "GeneFeature2"]]

# Target
y = data["Class"]

# Split Dataset
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=1, stratify=y
)

# Create Model
model = RandomForestClassifier(
    n_estimators=100,
    random_state=1
)

# Train Model
model.fit(X_train, y_train)

# Prediction
prediction = model.predict(X_test)

print("\nActual Class")
print(y_test.values)

print("\nPredicted Class")
print(prediction)

# Accuracy
accuracy = accuracy_score(y_test, prediction)

print("\nAccuracy:", round(accuracy * 100, 2), "%")

Q20. What is overfitting?

Answer: Overfitting occurs when a model performs well on training data but poorly on testing data.

Q21. What is underfitting?

Answer: Underfitting occurs when a model fails to learn important patterns and performs poorly on both training and testing data.

Q22. What is model evaluation?

Answer: Model evaluation is the process of checking how well a machine learning model performs using testing data and performance metrics.

Q23. What is Precision?

Answer: Precision measures how many of the samples predicted as positive are actually positive.
\[
Precision=\frac{TP}{TP+FP}\times100
\]

Q24. What is Recall?

Answer: Recall measures how many actual positive samples are correctly identified by the model.
\[
Recall=\frac{TP}{TP+FN}\times100
\]

Q25. What is F1-score?

Answer: F1-score is the harmonic mean of Precision and Recall. It helps evaluate the balance between them.
\[
F1=2\times\frac{Precision\times Recall}{Precision+Recall}
\]

Q26. What is a Confusion Matrix?

Answer: A Confusion Matrix is a table used to compare actual and predicted values of a classification model.

It contains four terms:
Term	Meaning
TP	True Positive
TN	True Negative
FP	False Positive
FN	False Negative

Q27. Explain TP, TN, FP and FN.

Answer:
- TP (True Positive): Actual positive and predicted positive.
- TN (True Negative): Actual negative and predicted negative.
- FP (False Positive): Actual negative but predicted positive.
- FN (False Negative): Actual positive but predicted negative.

Q4. What is Random Forest? Explain its basic working and advantages.
Answer:

Random Forest is a supervised Machine Learning algorithm used for classification and regression. It combines multiple decision trees to produce a final prediction.

Basic working:
1. Select random samples from the training dataset.
2. Create multiple decision trees.
3. Each decision tree makes its own prediction.
4. Combine the predictions using majority voting for classification.
5. The most commonly predicted class becomes the final output.







virtual-labs.github.io


Advantages of Random Forest:
1. Provides good prediction performance.
2. Reduces overfitting compared with a single decision tree in many situations.
3. Handles large datasets.
4. Works with multiple input features.
5. Can identify important features.
6. Can be used for both classification and regression.
Example: In genomic data classification, Random Forest can predict whether a sample is Healthy or Disease.
